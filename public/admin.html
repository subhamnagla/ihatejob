This page is public and shows only public data. It is served from a static site, so anything it could read, anyone could read. There is no login because there is nothing here to protect — it reads your public GitHub repository and your own config file, and nothing else. If you ever want private figures here, that needs a backend. An API token pasted into a page like this one would be readable by every visitor.

What this cannot show you, and why

Anyone's CV

CVs are held in each visitor's own browser storage and are never sent anywhere. There is no upload endpoint and no database. That is the promise on the front page, and it is the reason this section exists.

Who used it, or what they wrote

Nothing about a session is transmitted. The only way to know a visit happened is an analytics script, which counts page views — never content.

Per-user history

There are no accounts. Someone clearing their browser data starts from nothing, and no copy exists anywhere else.
